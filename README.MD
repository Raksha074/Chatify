# 💬 Chatify - Real-Time Chat Application

![MERN Stack](https://img.shields.io/badge/MERN-Stack-blue)
![Socket.io](https://img.shields.io/badge/Socket.io-RealTime-brightgreen)
![Cloudinary](https://img.shields.io/badge/Cloudinary-Image%20Upload-orange)

Chatify is a full-stack, real-time messaging application built with the MERN stack. It offers a seamless, WhatsApp-like chatting experience with features like instant messaging, media sharing, and secure authentication.

## ✨ Key Features

* **🔐 Secure Authentication:** User signup and login powered by JSON Web Tokens (JWT) and Bcrypt password hashing.
* **⚡ Real-Time Messaging:** Instant message delivery and live online/offline status updates using **Socket.io**.
* **🖼️ Media Sharing:** Direct image uploads from the browser seamlessly integrated with **Cloudinary**.
* **🎨 Modern UI/UX:** Responsive and beautiful interface crafted with React, Tailwind CSS, and Framer Motion.
* **🧠 State Management:** Fast and lightweight global state management using **Zustand**.
* **🗑️ Chat Management:** Ability to clear/delete chat history with specific users.
* **🕰️ Message Timestamps:** Real-time formatted timestamps for every sent and received message.

## 🛠️ Tech Stack

**Frontend:**
* React.js (Vite)
* Zustand (State Management)
* Tailwind CSS (Styling)
* Axios (API Requests)
* React Router DOM (Navigation)

**Backend:**
* Node.js & Express.js
* MongoDB & Mongoose (Database)
* Socket.io (WebSockets for real-time bi-directional communication)
* Cloudinary (Cloud media storage)
* JSON Web Token (JWT) (Authorization)
